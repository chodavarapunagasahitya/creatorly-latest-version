# Creatorly – AI Content Creator Marketplace

Creatorly is a modern AI-powered content creator marketplace designed to connect brands and clients with content creators through a seamless digital platform. It simplifies creator discovery, collaboration, booking management, and content planning through an intuitive and responsive user experience.

## Features

- **User Authentication:** Registration, login, and role-based access for clients and creators.
- **Creator Discovery:** Explore creator profiles, portfolios, and services.
- **Booking Management:** Submit, manage, and track creator booking requests.
- **Role-Based Dashboards:** Dedicated dashboards for clients and creators.
- **Notifications:** Stay informed about booking requests and project updates.
- **AI-Powered Assistance:** Support for creator matching, content ideation, pricing suggestions, and content quality checks.
- **Responsive Design:** A clean, modern interface optimized for desktop, tablet, and mobile devices.

## Technology Stack

- **Frontend:** React.js, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Deployment:** Render
- **Version Control:** Git and GitHub

## Deployment

The application is deployed using Render, with the frontend, backend, and database configured according to the project architecture.

**Live Application:** https://creatorly-latest-version-mbmw.onrender.com

## Project Objective

Creatorly aims to streamline the content creation ecosystem by providing a centralized platform for creator discovery, client collaboration, booking management, and AI-assisted content workflows.
